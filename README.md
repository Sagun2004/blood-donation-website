# Blood Donation Website

## Overview

A web-based Blood Donation Management System developed using Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript. The platform allows users to register, log in, and participate in blood donation camps.

## Features

* User Registration and Login
* Secure Password Encryption
* JWT Authentication
* Blood Donation Registration
* Donor Records Management
* Admin Dashboard
* MongoDB Database Integration

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB
* JWT Authentication

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Sagun2004/blood-donation-website.git
```

2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
node server.js
```
